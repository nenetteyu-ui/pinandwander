HERO SLIDESHOW IMAGES
=====================

Just drop image files into THIS folder and refresh the homepage — the theme
picks them up automatically. No renaming, no code changes.

- Any filenames are fine (e.g. santorini.jpg, kyoto.jpg).
- Supported types: .jpg  .jpeg  .png  .webp  .gif  .avif
- To REMOVE a photo from the slideshow, delete it from this folder.

SLIDE ORDER
-----------
Slides play in filename order (alphabetical / numeric). To control the order,
prefix names with numbers:

    01-santorini.jpg
    02-kyoto.jpg
    03-patagonia.jpg

HOW MANY?
---------
There's no hard limit, but every photo loads when the homepage opens, so keep
it reasonable — about 3 to 7 is the sweet spot. More than that mainly slows the
page down without adding much (visitors rarely wait through many slides).

IMAGE TIPS
----------
- Landscape orientation, ~2400px wide, high quality.
- Optimized JPG, ideally under ~500 KB each (try squoosh.app or tinyjpg.com).
- Striking but not too busy — the title and logo sit on top, so shots with a
  calmer/darker area (especially toward the bottom) read best.

If the folder is empty, the hero falls back to on-brand green/warm gradients.
